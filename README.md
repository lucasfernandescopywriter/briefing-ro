# 👗 Briefing Estratégico — Rô Modas
> **Projeto:** Presença Digital 360° · Do Planejamento ao Lançamento em 30 Dias  
> **Cliente:** Rô Modas (Moda Feminina · Masculina · Infantil)

Este repositório contém a página web de briefing interativo da Rô Modas. 
Ao responder o formulário na web, as respostas são automaticamente salvas como uma **Issue** neste repositório.

## 🚀 Como Acessar
O briefing está hospedado via **GitHub Pages**:
- **Link do Briefing:** [https://lucasfernandescopywriter.github.io/briefing-ro/](https://lucasfernandescopywriter.github.io/briefing-ro/)

## 📂 Arquivos no Repositório
- `index.html`: Aplicação web responsiva com envio direto para GitHub Issues.
- `Briefing_Ro_Modas.docx`: Versão minimalista em documento Word para download/preenchimento offline.
- `Briefing_Ro_Modas.md`: Versão em texto puro / Markdown do briefing.
